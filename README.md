# Agent 平台学习项目

通过「**精读生产级源码 → 仿写核心机制**」的方式，系统学习 AI Agent 平台的后端工程。

参考对象是一个真实运行的企业级 Agent 平台（源码不公开，精读笔记只保存在本地）。本仓库公开的内容是通用概念笔记，以及自己从零写的简化版实现。

## 学什么

一个 Agent 平台要解决的问题：让大模型能**调用工具、多轮推理、可被业务系统接入，并且整个运行过程可控、可观测**。

```text
业务系统 ──SDK──▶ API ──▶ Agent 循环 ──▶ 模型
                  │         │  ▲
                  │      中间件链│
                  │         ▼  │
                  │        工具调用（本地 / 远程回调）
                  ▼
             持久化：Run 状态、事件日志、会话上下文
                  │
                  ▼
             前端：配置台、调试台、运行轨迹
```

## 路线图

| 阶段 | 主题 | 学习重点 | 仿写目标 | 状态 |
|---|---|---|---|---|
| 0 准备 | 开发环境与协作文档 | JDK、Maven、Docker、Git | 环境验收通过 | [进行中](docs/plan/00-环境准备.md) |
| 1 全景 | 总体设计与模块边界 | 分层与依赖方向、用测试守护架构边界 | Maven 多模块骨架 + 依赖边界测试 | 未开始 |
| 2 Agent 循环 | ReAct 循环 | 模型 → 工具 → 回填结果 → 再推理；轮次与超时限制 | 纯 Java 迷你 Agent 循环（先用假模型） | 未开始 |
| 3 中间件 | 洋葱模型与生命周期 Hook | 责任链、包装调用、可选可排序 | 给迷你循环加中间件链 | 未开始 |
| 4 模型接入 | OpenAI 兼容协议与流式输出 | HTTP 流式响应、适配器模式 | 接入一个真实的兼容接口模型 | 未开始 |
| 5 工具体系 | 工具定义、版本、远程调用 | JSON Schema、幂等调用 ID、取消与超时 | 本地工具 + 简化版远程工具回调 | 未开始 |
| 6 持久化 | Run 状态机、事件日志、会话 | 数据库迁移、追加日志、并发与恢复 | 用 MySQL 保存 Run、事件和多轮上下文 | 未开始 |
| 7 接口与 SDK | HTTP API、SSE 推送、签名鉴权 | SSE、HMAC 签名、至少一次投递与去重 | 对外接口 + 流式推送 + 轻量客户端 | 未开始 |
| 8 前端 | 配置台、调试台、运行轨迹 | React、流式渲染、时间线可视化 | 简易调试页 + Run 时间线 | 未开始 |

## 每个阶段的学习循环

```text
精读（原理 + 源码）→ 仿写（简化实现 + 测试）→ 对照（找差异、想原因）→ 复盘（写笔记）
```
