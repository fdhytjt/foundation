# tutu · 知识库底座

一个用于学习后端工程的项目：从零实现「带权限、可检索、可接入外部数据」的知识库底座。

核心问题：**把分散的资料统一存起来，让每个人只能搜到自己有权限看的内容。**

## 路线图

| 阶段 | 内容 | 学习重点 | 完成标志 | 状态 |
|---|---|---|---|---|
| 0 准备 | 开发环境、Git 仓库、CLAUDE.md | 工程环境 | `java -version`、`mvn -v`、`docker ps` 正常 | 进行中 |
| 1 骨架 | 多模块 Spring Boot、统一返回、全局异常、健康检查 | 分层架构、Maven | `GET /health` 返回成功 | 未开始 |
| 2 登录 | 用户表、注册登录、Token、登录拦截器 | 拦截器、ThreadLocal、密码摘要 | 不带 Token 访问返回 401 | 未开始 |
| 3 功能权限 | 角色、权限码、`@RequiresPermission`、超管 | RBAC、声明式注解 | 普通用户调用管理接口被拒绝 | 未开始 |
| 4 组织架构 | 部门、岗位、上下级关系 | 树形结构、BFS | 能查询部门树和某人的全部下属 | 未开始 |
| 5 知识库 | 知识主体、正文、归属人、可见范围 | 数据库建模、事务 | 能新建和查看知识 | 未开始 |
| 6 检索 + 数据权限 | ngram 全文检索、主体标签、权限下推 SQL | 倒排索引、SQL 下推、越权测试 | A 搜不到 B 的私有知识 | 未开始 |
| 7 采集管线 | Connector / Normalizer / 编排器 / 水位 | 适配器模式、增量同步 | 本地文件夹的文档同步后可检索 | 未开始 |
| 8 调度与部署 | 定时同步、配置与密钥管理、Docker 部署 | 运维基础 | 一条命令启动整个服务 | 未开始 |

## 每个功能的开发循环

