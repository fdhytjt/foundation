# 设计决策记录

仿写过程中每个重要的设计选择写一篇，记录**当时为什么这样选**。以后回头看、或者想推翻时，先读这里。

**什么算重要决策**：影响多个模块、改起来成本高、或者有明显备选方案的选择。

**怎么写**：复制 `_模板.md`，文件名用 `编号-主题.md`（如 `001-模块划分.md`），编号递增，写完在下表登记。

> 公开记录只写自己仿写版的选择和通用理由。涉及参考项目具体实现的对照，写在本地 `private/notes/`。
