# 设计决策记录

每个重要的设计选择写一篇，记录**当时为什么这样选**。以后回头看、或者想推翻时，先读这里。

**什么算重要决策**：影响多个模块、改起来成本高、或者有明显备选方案的选择。比如 ORM 框架、Token 方案、权限模型。

**怎么写**：复制 `_模板.md`，文件名用 `编号-主题.md`（如 `001-选择ORM框架.md`），编号递增，写完在下表登记。
