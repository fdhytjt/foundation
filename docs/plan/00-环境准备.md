- [ ] **Git 基础**：提交、远程仓库、推送；为什么令牌能代替密码

## 注意事项（本机情况）

- 没有 Homebrew，访问国外下载源很慢。JDK 和 Maven 优先从**国内镜像站**下载（如清华大学开源软件镜像站）。
- Maven 下载依赖默认走国外中央仓库，需要在 `~/.m2/settings.xml` 配置阿里云镜像，否则阶段 1 编译会非常慢。
- Docker 拉取镜像也可能很慢，到阶段 2 需要 MySQL 时再处理镜像加速。
- 电脑是 Apple 芯片（arm64），下载时选择 **macOS aarch64 / arm64** 版本。
