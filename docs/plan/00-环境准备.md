## 目标

本机具备 Java 后端开发环境；项目仓库、协作文档和 GitHub 远程仓库就绪。

## 学习要点

- [ ] **JDK 是什么**：JDK（开发工具包）和 JRE（运行环境）的区别；为什么选 17 这个长期支持（LTS）版本
- [ ] **环境变量**：`JAVA_HOME` 和 `PATH` 各起什么作用，终端是怎么找到 `java` 命令的
- [ ] **Maven 是什么**：依赖管理（自动下载第三方库）和构建（编译、测试、打包）；中央仓库和镜像
- [ ] **Docker 是什么**：为什么用容器跑 MySQL，而不是直接装在电脑上
- [ ] **Git 基础**：提交、远程仓库、推送；为什么令牌能代替密码

## 决策

| 问题 | 决定 | 理由 |
|---|---|---|
| JDK 发行版 | Eclipse Temurin 17.0.20.1 | 免费、社区主流；17 是 LTS，也是 Spring Boot 3 的最低要求 |
| JDK 安装方式 | 下载 `.tar.gz`，解压到 `~/Library/Java/JavaVirtualMachines/temurin-17.jdk` | `.pkg` 需要管理员密码；macOS 的 `java_home` 同样会扫描用户目录下的这个位置，效果相同 |
| `JAVA_HOME` 写法 | `$(/usr/libexec/java_home -v 17)` | 每次打开终端时动态定位，JDK 升级后不用改配置 |
| Maven 安装方式 | 解压到 `~/tools/apache-maven-3.9.16`，加入 `PATH` | 不需要管理员权限，删除时删目录即可 |
| 下载来源 | 清华镜像（JDK、Maven）、阿里云（Maven 依赖）、JetBrains 官方（IDEA） | 国外源太慢 |

## 注意事项（本机情况）

- 没有 Homebrew。终端环境变量里配置了一个**远程 HTTP 代理**：访问国内镜像和 JetBrains 下载站时，走代理只有约 12KB/s，直连可达 2-3MB/s。命令行下载这些地址时用 `curl --noproxy '*'` 绕过代理。
- Java 程序（包括 Maven）默认**不读取** `HTTP_PROXY` 环境变量，所以 Maven 直连阿里云，不受这个代理影响。
- Docker 拉取镜像可能很慢，到需要 MySQL 的阶段再处理镜像加速。
- 修改 `~/.zshrc` 前已备份为 `~/.zshrc.bak-20260915`。
